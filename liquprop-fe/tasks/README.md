# LiquProp Task Files

This directory contains task files used to guide AI-assisted development with Claude Code or similar tools.

## How to use

Each numbered task file represents a development phase. To work on a phase:

1. Open the relevant task file (e.g. `02-components.md`)
2. Share it with your AI assistant along with a message like:
   > "Let's implement the tasks in tasks/02-components.md"
3. The AI will read the file and execute the tasks in order

## Task files

| File | Phase | Status |

| `01-setup.md` | Project bootstrap | ✅ Done |
| `02-components.md` | UI components | 🔲 Todo |

## Tips

- Keep task files focused and atomic — one concern per file
- Mark tasks as done (`[x]`) as you complete them
- Add new task files for features as the project grows
